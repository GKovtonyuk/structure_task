# structure_task
# Проєкт: Робота зі структурами в Python

## Опис проєкту
У цьому проєкті ми працюємо з даними про студентів, використовуючи структури даних у Python, такі як списки, словники або класи. Завдання полягає у створенні структури для зберігання інформації про студентів та фільтрації їх на основі оцінок.

### Призначення проєкту:
Реалізувати структуру даних для зберігання даних студентів і виконати фільтрацію студентів, що отримали оцінки 4 або 5.
